OpenSubdiv WASM Demo

CPU-Only WebAssembly Build

This demonstrates OpenSubdiv's CPU-only subdivision algorithms running in WebAssembly.

The demo creates a simple cube mesh and performs 2 levels of Catmull-Clark subdivision.

Technical Details

        
    
            
  • Library: OpenSubdiv v3.6.1
    • 
            
  • Build Type: CPU-only WASM build
    • 
            
  • Subdivision Scheme: Catmull-Clark
    • 
            
  • Input: 8 vertices, 6 faces (cube)
    • 
            
  • Refinement Levels: 2
    • 
            
  • Expected Output: 132 vertices, 126 faces
    • 
        

    


    

        
Build Configuration

        
This WASM build was configured with the following CMake flags:

        
emcmake cmake -B wasm-cpu-build \
    -DCMAKE_BUILD_TYPE=Release \
    -DNO_EXAMPLES=1 \
    -DNO_TUTORIALS=1 \
    -DNO_REGRESSION=1 \
    -DNO_DOC=1 \
    -DNO_OPENGL=1 \
    -DNO_METAL=1 \
    -DNO_DX=1 \
    -DNO_CUDA=1 \
    -DNO_OPENCL=1 \
    -DNO_CLEW=1 \
    -DNO_OMP=1 \
    -DNO_TBB=1 \
    -DNO_PTEX=1 \
    -DNO_GLFW=1 \
    -DNO_GLEW=1 \
    -DBUILD_SHARED_LIBS=OFF \
    -S .
